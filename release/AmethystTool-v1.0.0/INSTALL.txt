AmethystTool v1.0.0 - Instalacao

1. Feche a Steam completamente.
2. Copie os 3 arquivos DLL (AmethystTool.dll, dwmapi.dll, xinput1_4.dll)
   para a pasta raiz da Steam (onde esta o steam.exe).
3. Copie amethysttool.toml para a mesma pasta.
4. Adicione exclusao no seu antivirus para esses arquivos.
5. Inicie a Steam normalmente.
6. Verifique os logs em <Steam>\amethysttool\ para confirmar que o plugin carregou.

AVISO: Use apenas em conta Steam descartavel. Este plugin manipula DRM
e pode resultar em banimento da conta.
